# Projekt 1: Einfacher Taschenrechner

## Projektbeschreibung

In diesem Projekt entwickelst du einen einfachen Taschenrechner, der auf Benutzereingaben reagiert und mathematische Operationen durchführt.

Der Prozess soll folgende Schritte umfassen:

- Aufforderung zur Eingabe einer Gleitkommazahl.
- Aufforderung zur Auswahl eines mathematischen Operators.
- Unterstützt sollen mindestens die Operatoren: +, −, ×, /, //, %, ** sein.
- Aufforderung zur Eingabe einer zweiten Gleitkommazahl.
- Nach Eingabe der Daten soll der Taschenrechner die Operation auf der Konsole ausgeben.
- Abschließend erscheint eine Eingabeaufforderung, mit der man wählen kann, ob der Rechenvorgang wiederholt werden soll.

## Abgabe

Das endgültige Programm muss als reiner Python-Code unter dem Namen `calculator.py` eingereicht werden. Ein erster Prototyp kann in einem Jupyter Notebook entwickelt werden, muss aber für die Abgabe in eine Python-Datei (*.py) für die Ausführung außerhalb des Notebooks, beispielsweise in VS Code oder Spyder, übertragen werden.
