# Minesweeper💣💣💣

## Beschreibung

In diesem Projekt entwickeln wir ein Python-Programm für das Spiel Minesweeper.

Zuerst implementieren wir eine Konsolenversion des Spiels ohne Klassen, bei der wir Minesweeper direkt in der Konsole spielen können.

Anschließend erweitern wir das Programm, um eine Version mit Klassen und einer grafischen Benutzeroberfläche.

## Verwendung

Um das Spiel zu starten, führe das Programm aus.
